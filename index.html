Here is a checklist of the most common culprits to look for in your GitHub repository: 1. Check the File Location (Root Directory) Your index.html file must be located in the main, top-level folder of your repository. If you uploaded an entire folder from your computer and the index.html file is sitting inside it, GitHub Pages won't be able to find it. You will need to move it out into the main directory. 2. Verify Exact Spelling and Capitalization GitHub's servers are case-sensitive. Check the file list in your repository and ensure the file is named exactly index.html in all lowercase letters. If it has a capital letter (like Index.html or INDEX.HTML), GitHub will skip it and show your README instead. 3. Look for Hidden File Extensions Sometimes, computers hide file extensions by default. This means you might have named the file index.html on your computer, but its actual name ended up being index.html.txt or index.html.html when uploaded. Check the file name directly in the GitHub web interface to confirm it has the correct extension. 4. Give the Deployment a Minute GitHub Pages is not instant. Every time you upload or change a file, GitHub runs a background process to rebuild your site, which usually takes 1 to 3 minutes. You can check the Actions tab at the top of your repository to see the status. A spinning yellow circle means it is still building. A green checkmark means it is live. Once you have verified the file is named correctly and sitting in the main folder, wait for the green checkmark in the Actions tab. Then, go back to your website link and do a hard refresh (Ctrl + F5 on Windows, or Cmd + Shift + R on Mac) to bypass your browser's cache and see the new Mermazine homepage. Mermazine: For the Merfolk of East Anglia!

We first heard their siren call in the spring of 2019 and, the more we sought them, the more they began to emerge from obscurity: the beautiful, the grotesque, the perfect, the defaced, the badly restored, the lovingly created. Some might have been intended to convey Christian strictures about the sin of vanity, but this was only one tiny aspect of the wealth of meaning these wonderful creatures have carried across the centuries, much of which will be explored in depth in this and future issues of Mermazine.

Although we made many mermaid pilgrimages this summer, seven years ago by the time the days were shortening, we realised we had only scratched the surface of East Anglian mermaid lore. Perhaps we needed the intervening time period of the pandemic and beyond, to realise that this was too vast a topic to be compressed into book form. The merfolk seemed so much more from us than that, for one lay theme running through all that we had discovered was that of creative inspiration. Merfolk call us to write poetry, stories, learned articles, to draw and paint, to embroider, to make jewellery, to protest about the pollution of their waters.

With the launch of issue one, we are making a start, and Alice, Chris and Val hope that you too will be inspired by a glimpse in the mermaid's mirror, a flash of bright scales or the touch of a comb through your hair.
